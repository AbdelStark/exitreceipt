04 / REPRODUCE IT

One model.
A measurable definition of done.

The GLiNER2.5-Decide checkpoint runs locally. A rank-8 LoRA adapter trains on versioned examples; the best checkpoint is selected on development loss and compared with the base on task-template-held-out cases.

uv run --extra model exitreceipt train --data data/v2-cases.psv --evidence data/v2-evidence.psv --run-dir runs/v2 --device mps --epochs 3 --lora-dropout 0.1

Model revision, data hash, software versions, settings, and every prediction are recorded. See the v2 experiment contract for the exact method and limits.
