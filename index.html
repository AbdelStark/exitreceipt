The 340M-class GLiNER2.5-Decide checkpoint runs locally. A rank-8 LoRA adapter trains on versioned examples; the best checkpoint is selected on development loss and compared with the base on untouched test rows.

uv run --extra model exitreceipt train --run-dir runs/pilot --device mps

Model, data hash, versions, settings, and per-case predictions are recorded in the report. See the repository experiment contract for exact limitations.
