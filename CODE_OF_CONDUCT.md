# Code of conduct

Contributors and maintainers should discuss the work with respect, patience,
and technical specificity. Disagreement about a model result, benchmark, or
design is welcome; harassment, threats, personal attacks, and disclosure of
someone else's private information are not.

Maintainers may edit, hide, or remove contributions that break these rules and
may restrict participation when needed. If a concern can be described without
private details, open a repository issue. For sensitive conduct concerns, use
GitHub's report-abuse flow for the relevant account or content rather than
posting private details. For security vulnerabilities, follow
[SECURITY.md](SECURITY.md).
